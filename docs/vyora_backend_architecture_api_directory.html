1. Technical Stack & Engineering Rationale

The Vyora backend is engineered as a decoupled, multi-tenant modular monolith designed for horizontal scaling, absolute data integrity, and strict separation of business concerns:

Technology / Layer Selected Component Engineering Rationale & Architectural Purpose
Core Framework NestJS 11 (Express adapter) Provides enterprise architectural conventions: dependency injection, declarative routing, guards, interceptors, and modular domain encapsulation without microservices overhead.
Database & ORM MongoDB Atlas + Mongoose 8 Document-based persistence perfectly mirrors hierarchical financial documents (invoices with embedded line items). Multi-tenancy enforced through indexed businessId scoping.
Runtime & Language Node.js 20+ / TypeScript 5.8 Strict typing across all services, DTOs, and schemas. Zero implicit any. Compiles cleanly with tsc.
Authentication JWT + Passport + bcrypt Stateless JSON Web Tokens with 7-day expiration. Passwords securely hashed using bcrypt (salt rounds = 10). User memberships auto-link to business tenants.
Financial Mathematics Integer Minor Units (Paisa) Rule of Zero Float: Every financial value (prices, discounts, taxes, grand totals) is stored and computed in minor units (1 INR = 100 Paisa), eliminating floating-point rounding bugs.
Validation Engine Zod + @vyora/validation Shared, strict runtime validation schemas. Guarantees that payloads rejected by the frontend are also rejected by the backend with deterministic 400 error envelopes.
Security & Rate Limits Sliding-Window Memory Throttler In-memory rate limiter with periodic cleanup: 25 req/min on /auth/* (brute-force protection) and 200 req/min general. Automatic security headers (no-sniff, frame-options).
API Documentation Swagger / OpenAPI 3.0 Auto-generated interactive API documentation available at /api/v1/docs with Bearer auth support.

3. Non-Negotiable Backend Architectural Invariants

  • Multi-Tenancy Isolation (x-business-id): Every mutation and query is scoped to the tenant. TenantGuard extracts x-business-id from headers, verifies that the requesting JWT user is an active member of that business, and binds the verified ID. Requests with invalid or un-joined business IDs are rejected with 403 Forbidden.
  • Authoritative Calculation Engine: Frontend previews totals for user convenience, but the server calculates subtotals, CGST/SGST/IGST, rounding, and grand totals upon submission. Client-calculated totals are never trusted.
  • Immutability of Finalized Documents: Finalized invoices and purchase bills cannot be directly updated or overwritten. Any correction requires a formal cancellation flow with recorded reason and stock reversal.
  • Traceable Inventory Ledger: Direct stock overwrites are strictly forbidden. Stock level is altered only via verified movements: Sales deduction (SALE), Purchase addition (PURCHASE), or Manual Adjustment (ADJUSTMENT) with mandatory reason.
  • Idempotency Guarantees: Invoices and payment vouchers validate uniqueness constraints to ensure network retries cannot double-record bills or payments.

7. Quality Checks: The Five Layers

To eliminate regressions, guarantee strict typing, maintain uniform style, and prevent broken behavior from ever reaching production, Vyora enforces five defensive quality layers:

Layer Tool What It Catches Execution Command
1. Formatting Prettier Spacing, quotes, line width (printWidth: 100), trailing commas, so all code looks the same across files and team members. npm run format:check
npm run format
2. Linting ESLint + typescript-eslint Bugs, implicit any, unused code/variables, bad import order, hook mistakes, and unhandled promises. npm run lint
3. Type check tsc --noEmit (strict mode) Type errors, broken DTO contracts, undefined property accesses, missing function parameters, schema mismatches. npm run typecheck
4. Tests Vitest + Testing Library Behaviour that breaks: tax calculation regressions, stock overselling, unauthorized tenant leaks, broken endpoint status codes. npm run test
5. Gate Husky + lint-staged + CI Blocks bad code before commit and before merge. Automated pre-commit hook runs Layers 1–4 on staged files. Continuous Integration verifies full test matrix on PR. Pre-commit hook
& GitHub Actions CI

8. Quality Layer Execution & Verification Matrix

Mandatory Pre-Release Verification Protocol:
  1. Formatting Gate: Run npm run format:check across vyora-backend and vyora-frontend. All source files must comply with shared Prettier rules.
  2. Linting Gate: Run npm run lint. Zero ESLint warnings or errors permitted on production branches.
  3. Typecheck Gate: Run npm run typecheck (which runs tsc --noEmit). Both projects must compile with 0 errors.
  4. Behavioral Test Suite: Run npm run test. All NestJS controller, service, guard, and Vitest component tests must report 100% pass rate.
  5. Gatekeeper Certification: Run node scripts/ship-check.js. Validates secret leakage prevention, UI audit compliance, and build artifacts before release.
