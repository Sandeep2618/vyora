# Vyora Internationalization (i18n) Standards

> **Rule**: No hardcoded user-facing strings. Every label, button, error message, toast, and placeholder must use i18n translation keys.

---

## 1. Supported Locales

Vyora officially supports three languages across Web and Mobile:
1. **English (`en`)** — Master canonical dictionary
2. **Hindi (`hi`)** — हिंदी (Indian small business market)
3. **Gujarati (`gu`)** — ગુજરાતી (Western India trade & retail merchant hub)

---

## 2. Parity Invariant

- Every key defined in `en.ts` **MUST** also be present in `hi.ts` and `gu.ts`.
- If an automated test or code review detects a key missing in `hi.ts` or `gu.ts`, the build is marked as failing.
- Automated fallback: If a translation key is missing during runtime, the system falls back gracefully to the English key value, never rendering a raw key identifier like `dashboard.metrics.total_revenue`.

---

## 3. Namespacing & Key Convention

Translation keys must be strictly namespaced by domain: `<module>.<subfeature>.<property>`

```typescript
// Good:
"products.title": "Product Catalog",
"products.modal.create_title": "Add New Product",
"products.form.selling_price_label": "Selling Price (₹)",
"products.validation.name_required": "Product name is required",
"invoices.status.paid": "Paid",
"invoices.status.overdue": "Overdue",
"common.actions.save": "Save",
"common.actions.cancel": "Cancel",
"common.empty.no_records": "No records found"

// Bad:
"product": "Product",
"save_btn": "Save",
"err1": "Name required"
```

---

## 4. Parameter Interpolation

Use curly braces `{param}` for dynamic values:

```typescript
// en.ts
"invoices.details.invoice_number": "Invoice #{number}",
"products.stock.quantity_remaining": "{count} {unit} left in stock",

// Web Usage:
t('products.stock.quantity_remaining', { count: 12, unit: 'PCS' })

// Mobile Usage:
t('products.stock.quantity_remaining', { count: 12, unit: 'PCS' })
```

---

## 5. File Locations

- **Web Frontend**:
  - Master dictionary: `vyora-frontend/src/i18n/en.ts`
  - Hindi: `vyora-frontend/src/i18n/hi.ts`
  - Gujarati: `vyora-frontend/src/i18n/gu.ts`
- **Mobile App**:
  - Master dictionary: `vyora-app/src/i18n/en.ts`
  - Hindi: `vyora-app/src/i18n/hi.ts`
  - Gujarati: `vyora-app/src/i18n/gu.ts`
